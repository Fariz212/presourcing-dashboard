Buat Work Item Non-Project

Form cepat untuk request individual. Untuk Project dengan puluhan/ratusan site, gunakan Import Excel agar semua site masuk dalam satu Work Item.

Requirements

Import Excel / Paste dari spreadsheet

Pilih Work Type untuk membedakan Project multi-site dari Non-Project. Satu baris = satu site/requirement; Request ID yang sama menggabungkan baris menjadi satu Work Item.
Untuk Project: pilih Work Type=project pada setiap baris, gunakan Request ID yang sama untuk seluruh site, lalu isi Zona, Site, Alamat, Kode Pos, koordinat, harga referensi jika tersedia, dan Keterangan. Untuk Non-Project: pilih non_project atau kosongkan Work Type; aturan lama tetap berlaku. Jika file berisi beberapa Request ID tetapi sebenarnya satu project, pilih “Gabungkan SEMUA baris”; Request ID lama tersimpan sebagai External Reference. Preview sebelum import; import selalu membuat Work Item baru dan tidak mengubah data existing.
Semua Work Item dalam batch akan ditugaskan ke Buyer/PIC yang dipilih.
Pilih mode kedua jika file berisi banyak ID lokasi/permintaan sumber, tetapi semuanya sebenarnya satu project/request. ID per baris akan disimpan sebagai External Reference.
Gunakan satu ID induk yang unik. Preview akan menolak jika ID tersebut sudah digunakan.
Pilih file, atau copy tabel dari Excel lalu paste di area bawah. Jika keduanya diisi, file yang dipilih akan digunakan.
Operations reporting

Laporan bulanan Leasing

Rekap pekerjaan buyer, aktivitas yang tercatat, dan jumlah Request unik yang dikirim ke setiap vendor.
Project diproses sebagai satu Work Item dengan banyak site; gunakan Import Excel untuk intake Project massal. Definisi vendor: satu Work Item/Request ID dihitung satu kali per vendor per bulan, walaupun ada beberapa round outreach. Aktivitas dihitung dari actor yang mencatat; data Work Items menunjukkan owner saat ini.
Workbook berisi Monthly Summary, Work Items, Requirements - Sites (baris per site), Buyer Activity, Vendor Monthly Requests, Buyer x Vendor, Outreach Detail, dan Activity Log.

Hapus Work Item

Penghapusan permanen untuk memperbaiki kesalahan input. Metadata penghapusan akan tetap dicatat di audit.
Tindakan ini menghapus Work Item beserta site/requirement, outreach, penawaran, negosiasi, hasil, target komersial, dokumen terkait, dan activity log dari tampilan operasional. Aksi ini tidak bisa dibatalkan dari dashboard. Gunakan Tutup Work Item jika proses selesai, bukan salah input.
